# beyond Tiger HD CORPORATION Renewal Project

## Project Purpose
Rebuild and refine the beyond Tiger HD CORPORATION website as a strategic portfolio project for a web design and frontend engineering career opportunity.

This project is not simply a visual redesign. It aims to demonstrate brand thinking, information architecture, design decisions, implementation skills, and quality assurance.

## Project Goals
- Reorganize the corporate website experience.
- Improve brand storytelling and information architecture.
- Refine existing business content and introduce the food business concept.
- Build a consistent and intentional design system.
- Improve accessibility, responsiveness, usability, and implementation quality.
- Document the design and development process for portfolio presentation.

## Design Direction
Tentative direction:
Cinematic Corporate × Human-centered × Strategic Design

The design direction is not final and will be determined through research and planning.

## Core Brand Message
「可能性を超えていけ。」

Existing brand assets and corporate philosophy are to be reviewed and preserved where appropriate.

## Development Environment
- Editor: Visual Studio Code
- Workflow: VS Code integrated terminal
- Original theme: preserved separately
- Renewal project: independent working directory

## Working Principles
- Inspect before modifying.
- Never overwrite original project files without explicit confirmation.
- Separate confirmed facts, assumptions, and proposals.
- Discuss major design and structural decisions before implementation.
- Prioritize functionality, accessibility, responsive design, and quality.
- Keep the workflow reproducible through terminal commands whenever practical.

## Project Structure
